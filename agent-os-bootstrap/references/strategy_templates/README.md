# Strategy Templates - Index

This directory contains 10 strategy document templates. These are read by the BoS OS Bootstrap skill during Step 4 to populate strategy documents with company-specific content. Not for human consumption in normal use, however, if you do try this, let us know how it tastes.

## Templates

| File | Document domain | Example output name |
|------|----------------|-------------------|
| `values_template.md` | Company values and culture | `Our_Values.md` |
| `brand_template.md` | Brand and messaging | `How_We_Talk_to_the_Market.md` |
| `growth_template.md` | Growth and commercial logic | `How_We_Grow.md` |
| `product_template.md` | Product vision and north star | `What_We_Build_and_Why.md` |
| `financial_template.md` | Financial model | `How_We_Make_Money.md` |
| `governance_template.md` | Decision governance | `How_We_Make_Decisions.md` |
| `measurement_template.md` | Measurement and outcomes | `How_We_Know_Its_Working.md` |
| `security_template.md` | Information security and data | `How_We_Keep_Data_Safe.md` |
| `platform_template.md` | Platform and architecture | `How_We_Build.md` |
| `competitive_template.md` | Competitive positioning | `Where_We_Win.md` |

Output names are examples only. Use names that match how the company actually refers to these areas.

## How to use

Read each template to understand its structure, then populate the `[POPULATE: ...]` placeholders with real content from the company research conducted in Step 1. Do not use generic statements. Populate with specific information about this company.

Name each output file in plain English using the company's own language. Save to `02_STRATEGY/`.

Not every company needs all 10 documents. Use judgment. Skip or lighten templates that don't apply. See `industry_patterns.md` for guidance on which templates matter most by industry.
